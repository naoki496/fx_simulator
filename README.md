# MARKET LAB — 投資シミュレーター v0.3

高校生が、未来の値動きを知らない状態で投資判断を体験するための静的Webアプリです。個人情報の入力・送信・保存は行いません。

## 主な仕様

- 初期資産：1,000万円
- プレイ時間：5分
- 1銘柄、ローソク足60本（1本5秒）
- 固定プリセット：CASE A「成長と調整」／CASE B「乱高下」／CASE C「静かな転換」
- HISTORICAL「リーマン・ショック」（2008年9～11月のS&P 500を参考に再構成）
- 100／500／1,000株／最大の売買
- 売買手数料：0.15%
- 共通SEEDによる同一相場の再現
- 最大ドローダウン、最大投資比率、リスク調整スコアの表示
- 終了後のチャートに売買地点を表示
- PC／スマートフォン対応
- フレーム補間による滑らかな価格・ローソク足アニメーション
- 主要な操作ボタンの初回Tips表示（自動消去・手動消去対応）
- 白を基調にした親しみやすいインターフェース
- 急落時の控えめなMARKET ALERT表示
- 元本超過・元本割れを色と金額で常時表示

## GitHub Pagesへの配置

`dist` フォルダ内の3ファイルを、公開対象のルートに置いてください。GitHub Pagesの公開元をリポジトリ直下にする場合は、`dist` 内のファイルをリポジトリ直下へ移します。

同じ相場を配布する場合は、公開URLの末尾に `?scenario=A`、`?scenario=B`、`?scenario=C`、`?scenario=LEHMAN` のいずれかを付けます。

例：`https://example.github.io/investment-game/?scenario=B`

HISTORICALは、2008年秋の市場で確認された急落・急反発と期間全体の下落傾向を、教材用の60本へ圧縮したものです。特定銘柄の実際のOHLC値をそのまま再掲するものではありません。
